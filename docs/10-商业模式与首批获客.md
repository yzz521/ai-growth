# 10｜商业模式与首批客户获取方案

## 首发市场

长期目标用户可以广泛，但首发应聚焦：**内容驱动型个人经营者 + 1–5 人小团队**。优先访谈有持续业务、需要内容更新的个人创业者、小微企业老板和轻量代运营团队。先不同时服务大企业、复杂销售团队和所有外贸行业细分场景。

## 首版价值主张

“把你日常收集的微信、网页和文件整理成自己的知识库，再基于知识持续生成多平台内容。”不要承诺全平台自动运营、保证涨粉或保证获客。

## 初期收费假设

| 套餐 | 测试价格 | 面向对象 | 权益 |
|---|---:|---|---|
| Free | ¥0 | 体验用户 | 基础收集、1 个知识库、有限生成额度 |
| Pro | ¥49–99/月 | 创作者/个人创业者 | 多知识库、AI 整理、问答、内容生成 |
| Business | ¥299–699/月 | 小微企业/小团队 | 多成员、共享知识、审核、项目空间、额度池 |
| Agency | ¥999–1999/月 | 代运营团队 | 多客户空间、多品牌、批量内容和报表 |
| Enterprise | 定制 | 中大型企业 | 私有部署、集成、权限、审计和支持 |

这些价格是待验证假设，不是市场已验证价格。MVP 不接支付系统，先通过种子用户和人工收款验证价值。

## 盈利结构

基础订阅 + AI 额度包 + 团队/客户空间增值 + 企业部署。基础订阅含合理额度；图片/视频生成等高成本功能按量收费；企业权限、审计和私有部署单独定价。避免无限量套餐。按用户统计 Token、Embedding、解析、图片/视频、存储、流量和支持时间，计算毛利及续费。

## 首批客户获取：30 天实验

### 第 1 周：问题访谈

找 15 位目标用户：5 位个人经营者、5 位小企业经营者、5 位代运营从业者。让他们展示真实素材来源、内容生产和客户跟进流程；询问最近一次资料丢失、内容断更或漏跟进的真实损失。不要先演示产品。输出痛点排序、工作流地图、替代方案和付费障碍。

### 第 2 周：公开内容验证

连续发布 6–8 个真实演示：微信选定内容怎样变成知识；一份产品资料怎样生成四个平台草稿；AI 提取待办和客户需求；知识如何提示新旧资料冲突；小团队如何建立周内容流程。展示真实过程和人工审核，不夸大“全自动”。根据平台可用渠道人工发布。

### 第 3 周：免费体验工具

提供文章摘要/知识卡片、一主题多平台改写、个人知识库问答三个免费体验，引导用户加入试用并描述真实场景。未经用户许可不要公开其资料或案例。

### 第 4 周：付费验证

邀请 5–10 位高意向用户成为种子客户；陪同导入资料、沉淀知识和生成一周内容；测量从资料到可发布草稿的耗时；提供早鸟 Pro/小团队方案，要求真实付费验证，不以口头兴趣代替。

## 内容选题

- 我把微信收藏资料整理成个人知识库。
- 一份产品资料怎样变成小红书、抖音和公众号内容？
- 内容团队最浪费时间的不是写作，而是反复找资料。
- AI 知识库如何发现新旧报价冲突？
- 小微企业没有内容团队，如何建立每周内容流水线？

## 转化漏斗

`内容曝光 → 访问体验页 → 注册/试用 → 首次导入 → 知识沉淀 → 内容生成 → 首次发布 → 付费 → 续费`

逐环节统计转化率；先用真实访谈和行为数据验证，不用未经证实的行业平均值做目标。

## 渠道成本

社交平台官方 API 可能按调用量或套餐收费，权限需要审核，媒体处理和模型生成也有成本。平台 API 不是免费自动化通道，必须纳入单用户成本核算。
