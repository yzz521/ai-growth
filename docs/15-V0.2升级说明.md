# V0.2 升级说明

## 目标

V0.2 把原先“逐条点按钮”的本地 MVP，升级为以 AI 首页为入口、后台任务为执行层、品牌/内容配置为上下文的工作台。

## M1 页面与交互

- 新的 AI 首页：待处理信息、知识、内容、线索统计；后台任务；待审核知识；全局 AI 命令框。
- 信息流：单一粘贴入口、文件上传、自动整理状态和后台处理记录。
- 知识库：候选知识审核、正式知识检索、问答和版本编辑。
- 内容工厂：品牌/受众/策略选择、多平台生成、草稿编辑、审核、发布登记、内容日历。
- 增长分析：线索来源、内容数量、客户状态。
- 自动化任务：规则、启停、立即执行和运行记录。
- 配置中心：品牌、客户画像、内容策略、平台规则、提示词、自动处理偏好。

## M2 品牌和内容配置

- 品牌资料：行业、业务描述、产品服务、差异化、可核验案例、表达风格、CTA、禁用表达、默认品牌。
- 客户画像：细分人群、痛点、目标、顾虑、购买决策因素。
- 内容策略：内容支柱、比例、每周频率和业务目标。
- 平台规则：小红书、抖音、X、微信公众号独立 JSON 配置。
- 提示词模板：通用和平台专属模板；更新时版本号递增。
- 每条内容保存品牌、受众、策略、提示词版本和配置快照。

## M3 减少人工操作

- 文本和文件导入后触发后台自动整理。
- 可配置自动生成知识候选；候选知识经用户确认后进入正式知识库。
- 支持批量整理待处理收件箱。
- 内容生成自动读取默认品牌、受众、策略、平台配置和提示词。
- 全局命令支持整理资料、生成一周计划、今日简报和按输入目标批量生成草稿。
- 后台任务状态可查询，失败原因可见。

## M4 自动化与桌面体验

- 自动化规则：自动整理、每日简报、每周内容计划。
- 周期执行和执行历史。
- 本地目录监控导入。
- 可选全局快捷键剪贴板剪藏：用户主动复制并触发快捷键后提交工作台。
- 目录导入后自动触发整理，由服务端偏好控制。

## 数据升级与兼容

1. 先备份 data 目录（数据库和附件）。
2. 拉取 feat/v0.2-workspace-rework 分支并切换。
3. 执行原有启动脚本 run.sh 或 run.bat。
4. 首次启动自动创建 V0.2 表结构和默认平台规则。
5. 原有收件箱、知识、草稿和线索表不删除；新表通过 CREATE TABLE IF NOT EXISTS 增量创建。
6. 新前端位于 app/static-v2；旧前端文件保留，便于回退和对照。

## 桌面助手

安装可选依赖：

~~~bash
pip install -r requirements-desktop.txt
~~~

先启动工作台，再执行：

~~~bash
python desktop_helper/start_assistant.py
~~~

默认快捷键 Ctrl + Shift + Space。macOS 可尝试：

~~~bash
python desktop_helper/start_assistant.py --hotkey '<cmd>+<shift>+<space>'
~~~

快捷键仅在用户主动触发时读取当前剪贴板。操作方式：复制微信中选定的文字，再按快捷键。操作系统需要辅助功能/输入监听权限时，按系统提示授权。

## 当前明确不承诺的能力

- 不读取微信加密数据库，不注入微信进程，不静默监听聊天。
- 不模拟登录，不批量评论或私信。
- 不宣称四个平台已经自动发布。当前是内容生成、人工审核和发布登记；官方 API 连接器待逐个平台申请和验收。
- 自动化调度是本地单进程调度，不等同于分布式任务队列。
- 每日简报保存为执行结果，可在自动化历史中查看；本版不做邮件或微信推送。
- V0.2 仍是本地单用户版本，不可直接暴露公网。
