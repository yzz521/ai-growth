# 12｜升级路线图

## 当前版本：V0.2 Workspace Rework

- 新工作台与统一信息流。
- 品牌、受众、策略、平台规则和提示词配置。
- 导入后台自动整理及待审核知识候选。
- 多平台草稿、内容计划、发布记录。
- 自动化规则、后台任务、执行历史。
- 目录监控和用户主动快捷键剪藏。

## 阶段 1：可靠性与知识增强

1. 知识来源定位、版本差异、冲突检测。
2. 文件指纹、文本去重和相似候选。
3. 中文混合检索：BM25/全文检索 + pgvector。
4. Embedding 配置、索引重建和检索评测集。
5. 异步文档解析，OCR 插件化并保持可选。
6. 数据导出、删除、附件下载和自动备份。
7. 自动整理失败重试、幂等和任务恢复。

## 阶段 2：桌面应用体验

1. Tauri 桌面壳、托盘和启动项。
2. 用户可配置全局快捷键。
3. 选中文本主动剪藏、浏览器扩展剪藏。
4. 本地文件夹监控设置页、排除目录和文件类型。
5. 本地资料优先；用户选择后同步云端。
6. OS Keychain 保存模型密钥，避免明文配置。

## 阶段 3：正式 SaaS

- Vue 3 + TypeScript + Vite。
- Java 21 + Spring Boot 3 模块化单体，复用稳定业务 API 契约。
- PostgreSQL + pgvector、Redis、S3/MinIO。
- 认证、租户隔离、RBAC、审计、用量和计费。
- 逐步迁移数据，不一次性推翻当前本地数据结构。

## 阶段 4：官方平台连接器

- 按平台完成应用资质、授权审核、OAuth、Token 加密和刷新。
- 平台能力矩阵：授权、发布、数据读取、状态查询。
- 发布幂等、重试、配额、审核和操作审计。
- 按当前官方 API 实际权限决定是否自动发布，不用模拟登录兜底。

## 阶段 5：Agent 工作流

- 每日信息简报和知识更新提醒。
- 每周内容策划和多平台内容矩阵。
- 质量检查、事实来源核验和发布前审核。
- 线索识别、来源归因和客户跟进建议。
- Agent 工具白名单、执行预算、循环限制和人工审批。

## 阶段 6：企业与代运营版

- 多租户、团队成员和客户空间。
- 品牌隔离、内容审核和客户门户。
- 多账号、多项目和统一报表。
- 套餐、用量池、企业部署和数据保留策略。

## Go / No-Go

只有在核心闭环稳定、用户复访出现、真实付费意愿明确后，才投入 SaaS 化和官方平台发布集成。功能数量不是阶段成功指标。
