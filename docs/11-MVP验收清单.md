# 11｜MVP 验收清单

## 环境
- [ ] Python 3.10+ 可创建 venv。
- [ ] requirements 安装成功。
- [ ] run.sh / run.bat 启动服务。
- [ ] `/api/health` 返回 status=ok。
- [ ] UI 静态资源无 404。
- [ ] 默认只监听 127.0.0.1。

## 信息采集
- [ ] 文本粘贴成功入库。
- [ ] TXT/MD/CSV/JSON 导入成功。
- [ ] DOCX 段落和表格可提取。
- [ ] 可检索 PDF 可提取。
- [ ] 不支持文件类型拒绝上传。
- [ ] 超过 10 MB 返回 413。
- [ ] 空文件有清晰错误。

## 信息整理和知识
- [ ] 未配置 AI 时显示本地模板模式。
- [ ] 整理后摘要、标签、待办有结果。
- [ ] 沉淀后收件箱状态为 SAVED。
- [ ] 知识列表和关键词查询正常。
- [ ] 知识更新版本号递增。
- [ ] 问答返回来源，没有相关资料时明确说明。

## 内容
- [ ] 四个平台可以分别生成草稿。
- [ ] 关联知识 ID 被记录。
- [ ] 本地模板和模型生成状态可见。
- [ ] 编辑保存正常。
- [ ] 未审核草稿不能登记发布。
- [ ] 审核后可记录人工发布 URL。

## 线索
- [ ] 新增线索成功。
- [ ] 可以关联已有内容。
- [ ] 状态更新后仍持久化。

## 桌面助手
- [ ] 启动目录监控。
- [ ] 放入 Markdown 后进入收件箱。
- [ ] 导入成功后移动 processed。
- [ ] 服务不可用时源文件不应被移动。

## 备份
- [ ] backup.py 生成 ZIP。
- [ ] 包含 SQLite 快照。
- [ ] 有附件时包含附件。
- [ ] 按说明完成恢复测试。

## 上线前阻断项
- [ ] 登录、租户隔离、权限和审计。
- [ ] 隐私告知、同意、撤回、导出和删除。
- [ ] 远程模型数据处理说明和密钥管理。
- [ ] 官方平台授权和应用审核。
- [ ] AI 内容标识流程。
- [ ] HTTPS、限流、备份恢复和安全测试。
