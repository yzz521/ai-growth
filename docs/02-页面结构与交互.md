# 02｜页面结构与交互说明

## 一级导航

```text
工作台 Dashboard
信息收件箱 Inbox
知识中心 Knowledge
内容中心 Content Studio
客户线索 Leads
设置与连接 Settings
```

## 页面组成

### 工作台

顶部：产品名称、当前页、模型状态、刷新。指标卡：待处理信息、知识资产、待处理内容、开放线索。快捷入口：收集信息、知识问答、内容生成。列表：最近收集、最近内容。

### 信息收件箱

左栏：文本采集表单和文件上传。右栏：资料列表、摘要、标签、状态。操作：AI 整理、沉淀到知识。原文不覆盖，默认不自动沉淀。

### 知识中心

左栏：关键词搜索、知识列表、摘要、标签、版本号；右栏：问答、答案、来源；另有新建知识表单。后续补充知识详情、版本差异、冲突审核和关联图谱。

### 内容中心

创作表单：主题、受众、语气、平台和多选知识。草稿卡片：平台、标题、正文、状态。操作：编辑、保存、审核、复制、登记发布链接。

### 客户线索

录入客户、公司、联系方式、来源、关联内容、需求、预算、备注；展示状态统计及线索列表。

### 设置

模型配置状态；微信接入边界；平台发布策略；数据目录；备份说明；API 文档。

## 交互原则

- AI 生成结果可编辑。
- 状态变化有清晰标签。
- 接口失败展示明确错误，不静默吞掉。
- 危险操作需二次确认；当前 MVP 未提供批量删除。
- 移动端用于查看和轻量编辑，桌面端优先完成资料采集与内容创作。

## 视觉方向

浅灰背景、深色侧栏、低饱和绿色强调色；避免蓝紫渐变、过度发光卡片和 AI 模板化观感；优先保证信息密度和效率。
