# 08｜平台连接器与授权策略

## 原则

平台的开放范围、应用资质、审核、OAuth、配额和账号类型不同。不可假设所有渠道都支持全功能自动发布。Connector 应声明能力，而非将能力写死。

```json
{
  "platform": "douyin",
  "capabilities": {"oauth": false, "read_content": false, "publish_text": false, "publish_media": false, "read_metrics": false},
  "status": "NOT_CONFIGURED",
  "required_permissions": [],
  "last_verified_at": null
}
```

示意 JSON 中的 false 是未配置初始状态，不是对平台能力的事实判断。

## 平台策略

| 平台 | MVP | 正式接入前置工作 |
|---|---|---|
| 微信个人号 | 用户主动剪藏和文件导入 | 不将非官方聊天读取作为商业依赖 |
| 微信公众号 | 生成文章、人工发布、登记链接 | 按账号主体、接口权限和官方文档核验草稿/发布能力 |
| 小红书 | 生成笔记、人工发布 | 公开开放平台资料较多面向电商店铺/商家服务；普通笔记创作和发布能力需按实际应用资质与权限核实 |
| 抖音 | 生成脚本、人工发布 | 申请对应应用权限、OAuth 和内容发布 scope |
| X | 生成帖子和 Thread 草稿 | OAuth、写入权限、按量费用和速率限制核验 |

## 官方文档入口

- 小红书开放平台：<https://open.xiaohongshu.com/>；应用和权限说明需按开发者后台实际产品类目核验。
- 抖音授权：<https://developer.open-douyin.com/docs/resource/zh-CN/dop/ability/opensdk/user-authorization/solution>
- 抖音创建视频：<https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-video/video-create>
- 微信公众平台：<https://developers.weixin.qq.com/doc/offiaccount/>
- X Developer：<https://developer.x.com/>

平台规则会调整，上线前必须重新核对最新官方文档、资质条件、应用审核、权限列表、费用和服务条款。官方文档的存在不代表当前账号已经获得相应权限。

## 建议 Connector 接口

```python
class PlatformConnector:
    def capabilities(self) -> dict: ...
    def authorize(self, callback_url: str) -> dict: ...
    def refresh_token(self) -> dict: ...
    def publish(self, content: dict) -> dict: ...
    def get_publish_status(self, external_id: str) -> dict: ...
    def get_metrics(self, external_id: str) -> dict: ...
```

未获授权的方法应返回 `CAPABILITY_NOT_GRANTED`，不允许模拟登录作为 fallback。

## 正式发布状态机

`DRAFT → REVIEWED → AUTHORIZED → QUEUED → PUBLISHING → PUBLISHED / FAILED`。

发布日志至少保存授权账号、scope、调用请求 ID、平台返回 ID、时间、失败原因、重试次数和操作人。Token 加密存储，不保存平台密码。发布前显示目标账号、内容预览和发布时间；失败重试考虑幂等。
