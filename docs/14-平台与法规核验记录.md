# 14｜平台与法规核验记录

核验日期：2026-11-09。平台授权、价格和规则可能调整；下列信息用于技术方案初筛，不能替代实际应用审核或法律意见。

## 平台

### 微信个人号

本项目不把读取个人微信内部数据库或非官方协议作为方案。个人微信聊天数据按用户主动选取、导入、剪藏处理。不要把“客户端备份/导出能力”推断成第三方 SaaS 可直接读取的开放 API。

### 微信公众号

官方文档入口：<https://developers.weixin.qq.com/doc/offiaccount/>。具体草稿、素材、发布能力取决于公众号主体、接口权限、认证和当期官方规则。开发前用实际公众号后台和接口权限核实。

### 小红书

官方开放平台：<https://open.xiaohongshu.com/>。

公开的开发者文档资料可见店铺授权、商家自研/第三方应用和电商/商品类能力；这不等于普通个人创作者笔记的普遍发布接口已经开放。产品首版采用内容生成和人工发布，不承诺自动发布笔记。正式接入前应确认申请主体、应用类目、数据用途、授权账号和具体 API scope。

参考：
- 开放平台首页及应用方向：https://open.xiaohongshu.com/
- 授权流程示例：https://open.xiaohongshu.com/document/developer/file/38
- 应用类目说明：https://open.xiaohongshu.com/document/developer/file/33

### 抖音

官方授权说明：<https://developer.open-douyin.com/docs/resource/zh-CN/dop/ability/opensdk/user-authorization/solution>。官方创建视频接口文档列有 `video.create.bind` scope，并注明需要申请相应权限；授权用户后才能按允许的 scope 调用。

参考：
- 用户授权：https://developer.open-douyin.com/docs/resource/zh-CN/dop/ability/opensdk/user-authorization/solution
- 创建视频：https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-video/video-create

### X

X Developer 官方站当前介绍按资源消耗计费（Pay-Per-Use），而不是简单假设固定免费额度。价格页面在本次查询显示 Post Create 按请求计价，页面示例单价为 USD 0.015/次；正式开发和商业测算必须再次核对最新价格、税费、配额和接口范围。

参考：<https://developer.x.com/>。

## 法规和内容标识

### 个人信息保护

《个人信息保护法》规定个人信息处理的合法基础、告知、同意、撤回、敏感个人信息保护及删除等权利和义务。网络数据处理相关规则进一步强调处理规则的可访问性及处理目的、方式、类别、保存期限和权利行使途径。

参考：
- https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm
- https://www.cac.gov.cn/2024-09/30/c_1729384452307680.htm

### AI 生成合成内容标识

《人工智能生成合成内容标识办法》及配套强制性国家标准自 2025-09-01 起施行。面向境内发布内容时，需要评估生成内容标识和用户主动声明要求，并结合具体平台的标识工具完成发布前检查。

参考：
- https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm
- https://www.cac.gov.cn/2025-03/14/c_1743654685896173.htm
