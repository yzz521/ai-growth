# 03｜技术架构与技术选型

## 当前 MVP 架构

```text
Browser（原生 HTML/CSS/JS）
  └─ same-origin REST
       └─ FastAPI 模块化单体
            ├─ Inbox / Knowledge / Content / Lead services
            ├─ 文件解析器 TXT/MD/CSV/JSON/PDF/DOCX
            ├─ OpenAI-compatible AI Adapter
            └─ Static Web UI
       ├─ SQLite（业务和版本）
       ├─ data/uploads（原始文件）
       └─ Desktop Helper（主动导入目录）
```

## 当前技术选择

| 组件 | 当前选择 | 原因 | 后续目标 |
|---|---|---|---|
| API | Python + FastAPI | AI/文档生态成熟，启动快 | Java 21 + Spring Boot 3 业务主服务 |
| 前端 | 原生 HTML/CSS/JS | 无构建链，个人开发部署简单 | Vue 3 + TypeScript + Vite |
| DB | SQLite | 单机零配置 | PostgreSQL |
| 检索 | 关键词基线 | 快速验证 | PostgreSQL FTS/BM25 + pgvector |
| 文件 | 本地目录 | 本地优先 | S3/MinIO |
| 模型 | OpenAI-compatible API | 减少单一厂商耦合 | 模型网关和成本路由 |
| 任务 | 同步 API + 本地轮询 | MVP 任务量小 | Redis + 队列/工作流 |
| Agent | 显式业务服务函数 | 易审计，减少过度 Agent 化 | LangGraph 可恢复工作流 |
| 发布 | 人工发布登记 | 权限可验证、稳定 | 官方 API Connector |

## 为什么不先上微服务

个人开发者需要优先降低部署、调试和运维负担。当前瓶颈是产品闭环和平台授权，不是服务吞吐。模块通过独立服务层和 API 边界组织，后续再按实际负载拆分。

## 模型适配器

环境变量：`AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL`、`AI_TIMEOUT_SECONDS`。当前请求 `/chat/completions`，JSON 输出采用基础解析。正式版补充 Provider 接口、JSON Schema 校验、重试退避、并发限制、预算、用量日志、敏感信息脱敏、Prompt 版本和评测集。

## 检索能力

当前不是向量 RAG。系统从知识标题、摘要、标签和正文提取英文词及中文相邻字对，计算重合程度。配置模型后将候选来源片段交给模型，并要求来源标注。中文关键词检索只是 baseline，不能等同于准确语义检索。

升级：Embedding、pgvector、BM25/FTS 混合检索、重排、引用定位和离线评测。

## 桌面助手

```text
用户主动保存/导出 → data/dropbox → watch_folder.py
 → POST 127.0.0.1:8000/api/inbox/upload → FastAPI 入库
 → data/dropbox/processed
```

不访问微信进程、数据库、令牌或私有协议。未来可用 Tauri/Electron 增加托盘和用户主动快捷键，但要有可见状态和授权提示。

## 正式 SaaS 目标架构

```text
Vue 3 Web / Tauri Desktop
       ↓
Auth / Tenant Context / API Gateway
       ↓
Java 21 + Spring Boot 模块化单体
  ├─ Identity & Tenant
  ├─ Inbox & Source
  ├─ Knowledge & Version
  ├─ Content & Calendar
  ├─ Connector & Publish
  ├─ Lead & Attribution
  ├─ Billing & Usage
  └─ Audit & Policy
       ↓ 内部 API / 事件
Python AI Service（解析、Embedding、RAG、LangGraph、内容生成、评测）
       ↓
PostgreSQL + pgvector / Redis / Object Storage
```

Java 负责授权、业务状态和数据持久化；Python 负责模型、RAG 和 Agent。AI 不得直接任意写业务表。先做模块化单体，按实际瓶颈拆服务。

## 安全原则

本地 MVP 默认 localhost，无公网认证。API Key 从环境变量读取；上传有扩展名白名单、大小限制和随机存储名；SQL 参数化；外部资料视为不可信输入；云模型调用前提醒数据去向。
