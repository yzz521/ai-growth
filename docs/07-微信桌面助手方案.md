# 07｜微信桌面助手方案

## MVP 实现

桌面助手是用户主动采集工具，不是微信客户端增强插件。

- `capture_text.py`：将用户选定文本写入本地 Markdown。
- `watch_folder.py`：轮询 `data/dropbox/`，上传支持格式到本机 FastAPI。
- 上传成功后移动至 `processed/`。
- Web UI 中查看、整理和沉淀。

## 可用场景

- 用户选中微信聊天中的部分文字，主动复制并剪藏。
- 用户手动导出或备份得到可读文件，再选择性导入。
- 微信收到 PDF/Word 等资料，用户主动保存到目录。
- 公众号或网页内容由用户保存为可读正文/文件后导入。

## 明确不做

- 读取微信加密数据库或密钥。
- 注入微信进程、Hook 私有 API、模拟客户端通信。
- 自动登录、绕过验证码或设备安全验证。
- 未经明确操作持续监听和上传剪贴板。
- 未经授权批量收集联系人或群成员资料。

## 后续桌面应用

可用 Tauri（Rust）或 Electron 封装 Web 工作台，优先实现：

1. 系统托盘和快速打开。
2. 用户主动快捷键保存当前选中文本。
3. 剪贴板读取前显示权限说明，按键触发，不做后台静默监听。
4. 文件夹监控和拖放。
5. 本地解析与脱敏预览。
6. 用户选择是否上传云端、是否发送远程模型。
7. 同步状态、失败重试和本地缓存。
8. 暂停同步、撤回授权和删除本地缓存。

## 本地与云端分工

| 本地 | 云端（后续） |
|---|---|
| 用户主动采集 | 账号、知识、内容和业务管理 |
| 本地文件解析 | 跨设备同步 |
| 敏感信息预览/脱敏 | AI 生成和协作（用户授权后） |
| 离线暂存 | 模型路由、内容工作流和线索归因 |

核心原则：用户始终知道采集了什么、传到哪里、调用哪个模型、保存多久。
