# 00｜产品边界与关键决策

## 产品定义

**AI Growth Workspace：个人与小微团队的知识驱动型 AI 工作台。**核心承诺：把分散信息整理成可信、可追溯、可更新的知识资产，再利用这些知识辅助内容创作和客户增长。

闭环：`信息采集 → AI 整理 → 人工确认 → 知识沉淀 → 内容生产 → 人工审核/发布 → 线索记录 → 效果反馈`。

## 长期用户与首发聚焦

长期覆盖个人创业者、销售、自媒体创作者、小微企业、外贸公司、内容团队和代运营机构。首发聚焦**内容驱动型个人经营者及 1–5 人小团队**。原因：资料管理、持续创作和客户获客三类需求能在同一场景出现，决策链短，适合个人开发者验证。

## 三层产品能力

1. Personal Knowledge OS：统一收件箱、资料解析、知识库、版本、来源。
2. AI Agent Workspace：信息整理、知识问答、内容生成等可控任务执行。
3. Growth & Marketing OS：多平台内容适配、人工发布记录和线索归因基础。

## MVP 核心场景

用户把一段自己有权处理的微信文字或一份文件放入系统；AI 总结和分类；用户确认后沉淀知识；选定知识生成公众号、小红书、抖音及 X 草稿；人工审核发布；登记发布链接和咨询线索。

## 当前已实现

- 本地单用户 Web 工作台。
- 文本粘贴、文件上传及目录监控导入。
- TXT/MD/CSV/JSON/可检索 PDF/DOCX 解析。
- AI 摘要、标签、事实候选、待办候选。
- 知识沉淀、关键词检索、问答和版本记录。
- 四个平台内容草稿生成。
- 编辑、人工审核、发布记录和线索登记。
- SQLite 本地数据和 ZIP 备份。

## 当前未实现

- 微信全量同步、微信内部数据库读取、企业微信会话存档集成。
- 社交平台 OAuth 和自动发布。
- 向量数据库、Embedding、语义检索、OCR。
- 自动评论、自动私信、自动关注和自动获客。
- SaaS 注册登录、多租户、团队权限、支付和云同步。

## 关键原则

- 原始资料不被覆盖；摘要、提取结果和人工确认结果分开。
- 重要知识有来源、时间和版本；冲突时提醒，不擅自覆盖。
- AI 建议不等于事实；价格、合同、政策和客户信息需要人工核验。
- Agent 仅调用白名单工具；写入和发布等敏感动作需要授权。
- 本地优先；发送远程模型前明确数据去向。
- 平台连接器、模型适配器与核心业务解耦。

## 个人开发者取舍

首版采用 FastAPI + SQLite + 原生 Web UI，而不是一开始搭建 Java/Vue 多服务系统，以减少构建和运维负担。产品达到付费验证门槛后，再迁移到 Java 21 + Spring Boot 3、Vue 3、PostgreSQL 的 SaaS 主架构，Python 保留为 AI 服务。
