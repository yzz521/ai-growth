# 06｜部署与运行手册

## 本地环境

Python 3.10+；建议 3.11/3.12。macOS、Windows、Linux 均可。

## macOS / Linux

```bash
unzip ai-growth-workspace.zip
cd ai-growth-workspace
chmod +x run.sh
./run.sh
```

脚本创建 `.venv`、安装依赖、复制 `.env.example` 为 `.env`，再以 `127.0.0.1:8000` 启动。

## Windows

```bat
cd ai-growth-workspace
run.bat
```

PowerShell 手动方式：

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

## 地址

- UI：`http://127.0.0.1:8000/`
- API 文档：`http://127.0.0.1:8000/docs`
- 健康：`http://127.0.0.1:8000/api/health`

## 模型配置

编辑 `.env`：

```env
AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=your_api_key
AI_MODEL=your_model_name
AI_TIMEOUT_SECONDS=60
```

重启服务。若供应商不支持 `/chat/completions` 或要求特殊参数，需要单独实现适配器。

## 桌面助手

```bash
python desktop_helper/watch_folder.py
```

自定义地址：

```bash
python desktop_helper/watch_folder.py --api http://127.0.0.1:8000
```

## 自动化测试

```bash
pip install -r requirements-dev.txt
pytest -q
```

## 备份和恢复

备份：

```bash
python scripts/backup.py
```

恢复：停止服务，先复制当前 `data/`；解压备份 ZIP，将 `app.db` 放回 `data/app.db`，将 `uploads/` 恢复到 `data/uploads/`。恢复后启动并检查健康接口和关键记录。

## 数据目录

- `data/app.db`：SQLite。
- `data/uploads/`：上传原文件。
- `data/dropbox/`：桌面导入目录。
- `data/dropbox/processed/`：导入成功的文件。
- `data/backups/`：备份 ZIP。

## 常见问题

| 问题 | 排查 |
|---|---|
| 8000 端口占用 | 配置 AGW_PORT，并同步桌面助手 --api |
| AI 未配置 | 编辑 .env 后重启 |
| AI 调用失败 | 检查 URL、模型名、额度、网络、超时 |
| 文件上传失败 | 检查格式、大小和 PDF 是否可检索 |
| DOC 无法解析 | 当前支持 DOCX，不支持旧 DOC |
| 扫描 PDF 无文字 | 当前无 OCR，先转可检索 PDF |
| 文件未被桌面助手导入 | 检查服务和监控脚本是否运行、扩展名是否支持 |

## 公网部署禁止事项

当前无用户认证和租户隔离。不得将服务绑定到 `0.0.0.0` 后直接暴露公网，也不得直接反向代理到互联网。公网化必须先完成 `docs/09-安全与隐私.md` 中的阻断项。
